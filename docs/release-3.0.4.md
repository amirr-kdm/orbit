## Orbit 3.0.4 (Mac)

> **New accounts need the admin's approval.** For faster approval, message me on Telegram: [@amirr_kdm](https://t.me/amirr_kdm)

### 🍎 Mac
- **⌘B** shows and hides the sidebar.
- **Tasks**: "Time needed" for a to-do with a progress bar, the timer starts with that time, a study summary on every day header, add one to-do on several days at once, a collapsible "No date" bar, and a red **Not done** for tasks from weeks that are over.
- **Notch / sound**: the volume key going to zero now also mutes, so nothing stays audible.
- **Less heat**: the "Are you still there?" panel no longer keeps animating (and using the CPU) after you close it.
- The notch no longer leaves content hanging outside its shape when it shrinks.
- Your name and rights come back by themselves after a slow start without internet.
- Friends: a friend whose clock is ahead no longer shows a negative study time.
