## Orbit 2.4.3

> **New accounts need the admin's approval.** For faster approval, message me on Telegram: [@amirr_kdm](https://t.me/amirr_kdm)

### 📡 No internet? You are told, and you're never stuck
- If the internet is down when you take a **Level Pass** reward, Orbit now says so (instead of doing nothing) and lets you leave with **OK** or **Leave**. Your reward is safe: open the Level Pass again when you're online and press **Claim**.
- Buttons show "Claiming…" while the server is working, and the reward is only shown as taken once the server has confirmed it.
- Every request now gives up after 20 seconds with a clear "No internet connection" message, everywhere in the app (Mac and Windows).

### 🪟 Windows fixes
- **Touchpad pinch** now zooms the galaxy and the task graph (the Windows app was blocking the pinch gesture).
- The **zoom bar** in the corner of the galaxy works, and it has − / + buttons. A mouse-wheel notch with Ctrl no longer jumps to the end.
- **Drag and drop** (moving tasks between days, planner items) works in the Windows app.
- Admin notifications for new sign-ups and gift notices show as real Windows notifications.
- Very large galaxy pictures can't turn blank any more.
